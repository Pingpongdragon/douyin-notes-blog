7 个 DSH 插件清单：从桌宠到抖音自动化

作者：小汐 · 7699861376985992448 · 2026-11-09

一句话总结小汐列出 7 个 DSH 插件：dsh-pet、dsh-douyin-browser-local、dshmarket、dsh-whale-widget、dsh-ops、billion-context、dsh-boot-animation，并更正市场名是 dshmarket。

一句话总结

这条视频是一份 7 个 DSH 插件的清单：从蓝色大肥鱼桌宠、抖音自动化、可视化插件市场，到余额挂件、bash 工具、上下文压缩和开机动画，并顺手更正了插件市场的名字是 dshmarket（没有中间的横杠）。

视频讲了什么

作者先纠正上一期的一个错误：插件市场叫 dshmarket，不是 dsh-market。因为不少人反馈评论区看不到链接，所以把 7 个插件的 GitHub 地址统一放进了视频简介和另一个号的作品里。

清单按顺序是：dsh-pet（蓝色大肥鱼桌宠，会吃白饭、扔魔方、陪唠嗑）、dsh-douyin-browser-local（让大肥鱼自己刷抖音）、dshmarket（可视化插件市场，逛一逛点一下装好）、dsh-whale-widget（右下角余额小鲸鱼挂件）、dsh-ops（文件与命令工具，Windows 也能跑 bash）、billion-context（上下文压缩，百 K 窗口也够用）、dsh-boot-animation（每次打开 DSH 播一次片头动画）。

视频本身是“大肥鱼刷抖音教学”系列的一条，重点在给 DSH 用户一份可直接照着装的插件入口，而不是逐个深入讲实现。每个插件只给了一句定位和 GitHub 地址，适合当索引，不适合当教程。

关键点

  • dsh-pet：桌宠型插件，吃白饭、扔魔方、陪聊，偏娱乐和陪伴。
  • dsh-douyin-browser-local：让 DSH 里的“大肥鱼”自己刷抖音，属于内容/自动化方向。
  • dshmarket：可视化插件市场，搜索、点按安装；注意名字没有横杠。
  • dsh-whale-widget：右下角余额小鲸鱼挂件，随时看余额。
  • dsh-ops：文件与命令工具，Windows 上也能跑 bash。
  • billion-context：上下文压缩，缓解百 K 窗口不够用的问题。
  • dsh-boot-animation：每次打开 DSH 播一次片头动画，纯外观。

适合谁看

刚装好 DSH、想快速补齐常用插件的人；以及喜欢桌宠、余额挂件、开机动画这类“非生产力但好玩”插件的人。视频只给入口和一句话定位，装之前最好逐个看仓库 README，确认权限和兼容版本。
