5 款 DSH 插件：市场、皮肤、记账、上下文监控与压缩

作者：JIE.7 · 7702754029906021686 · 2026-11-24

一句话总结五款插件：dsh-market 集中管理、dsh-skin-market 美化、余额鲸鱼挂件看消耗、dsh-context 监控 Token 去向（不自动压缩）、billion-context 把旧记录摘要化；按需安装，不必全装。

一句话总结

这条视频整理了 5 款 DeepSeek Harness 插件：插件市场、皮肤市场、余额挂件、上下文监控、长上下文管理；从“装插件”到“看 Token 花在哪”，覆盖工作台的美化和成本可观测。

视频讲了什么

第一款 dsh-market 是插件市场：找插件、安装、更新、卸载集中在一个入口，减少到处翻 GitHub 项目的麻烦。第二款 dsh-skin-market 是皮肤市场：开屏动画、界面皮肤、桌宠外观，属于“让工作台顺眼”的一类。

第三款 DeepSeek-Balance-Whale-Widget 是小鲸鱼记账挂件：余额、今日消耗、单轮对话预估费用抬眼就能看到，还支持预算提醒。视频特别说明，查看真实余额需要配置 API Key 或对应账号登录；没有 Key 时只能看估算。

第四款 dsh-context 是上下文监控：看 Token 花在哪，包括使用量、上下文趋势、文件活动、工具调用。视频强调它只负责监控，不会自动压缩上下文——不要把“看见”当成“解决”。

第五款 billion-context 是长上下文管理：像“笔记整理员”，把较早的记录整理成可引用的摘要，最近对话保持原样，减少重复内容占用的空间。它和 dsh-context 的分工是：一个压缩、一个观测。

整体是按需挑选：先装市场方便管理，再按需要加美化、记账、监控、压缩；不是五个都必须装。

关键点

  • dsh-market：插件集中管理，找/装/更新/卸载。
  • dsh-skin-market：开屏、皮肤、桌宠外观。
  • 余额挂件：余额、今日消耗、单轮预估、预算提醒；真实余额需 Key/登录。
  • dsh-context：Token 使用量、趋势、文件与工具调用监控；不自动压缩。
  • billion-context：旧记录摘要化，最近对话保留，降低重复占用。
  • 按需安装：先市场，再按美化/成本/上下文需求加装。

适合谁看

刚用 DSH、想快速把工作台配顺手的人；以及 Token 花得快、想知道钱花在哪的人。视频是插件清单，具体安装与配置以各仓库说明为准。
