DSH 桌面端配置：安装、API、开机动画与桌宠

一句话总结教程覆盖桌面端安装、API 配置、开机动画与桌宠；通过指令让 Agent 找 MerZlin/dsh-pet-indesktop 与 dsh-video-skin，并安装配置到合适位置，重点是描述目标而不是背命令。

一句话总结

这条 DSH 桌面端教程把三件事串起来：桌面端安装、API 配置、开机动画与桌宠配置；后两项直接让 Agent 去 GitHub 找项目并装到合适位置，适合想一次把“能用的 DSH”配齐的人。

视频讲了什么

文案先给范围：桌面端安装、API 配置、开机动画与桌宠。它没有停在“装完能打开”，而是继续把外观和常驻能力配上，让 DSH 更像一个日常工具，而不是一次性试用。

桌宠部分给了具体指令：让 Agent 去 GitHub 找 `MerZlin/dsh-pet-indesktop`，并安装配置到电脑上的合适位置。这里的重点不是手动 clone，而是把“找项目、看说明、选安装位置、配置”交给 Agent 执行；用户只需要把目标说清楚。

开机动画与视频背景部分同样给了指令：让 Agent 在 GitHub 找 `dsh-video-skin` 插件，安装并配置，使每次双击桌面上的 DSH 时出现开机动画，进入后有视频动态背景。文案没有展开插件内部参数，能确定的是它把“启动画面 + 动态背景”打包成一个可配置的皮肤插件。

从两条指令能看出这套教程的方法：先描述目标（要什么效果、装在哪），再让 Agent 去找仓库、读 README、执行安装。这样即使项目更新、路径变化，也不用背固定命令；但前提是用户能判断安装位置和权限，避免装到系统目录或覆盖已有配置。

关键点

  • 三块内容：桌面端安装、API 配置、开机动画/桌宠。
  • 桌宠项目：`MerZlin/dsh-pet-indesktop`，让 Agent 找并装到合适位置。
  • 开机动画/背景：`dsh-video-skin`，双击启动出现动画，进入后有动态背景。
  • 用指令驱动：描述效果与安装位置，让 Agent 去 GitHub 找、读说明、配置。
  • 注意边界：安装位置、权限、是否覆盖现有配置，需要自己确认。

适合谁看

刚装好 DSH、想把 API、桌宠、开机动画一次配齐的人；以及想学“怎么让 Agent 去 GitHub 找项目并安装”的人。教程偏实操，具体插件参数以仓库 README 为准。
