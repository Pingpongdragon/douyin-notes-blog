从零搭一个 Agent：四块框架与七步上岗

作者：新一Ai · 7680489379543123643 · 2026-11-14

一句话总结用四块内容讲搭 Agent：Agent 是什么、长什么样、由什么组成（Skill/CLI/MCP），以及从建工位到新窗口验证上岗的七步；全程不写代码，重点是任务拆解、skill 与工具配置。

一句话总结

这条视频想用“四块 + 七步”把搭 Agent 讲完整：先搞清 Agent 是什么、长什么样、由什么组成（Skill/CLI/MCP），再从建工位到新窗口验证上岗，走完一套不写代码的流程。

视频讲了什么

文案给了一个很清晰的结构：四块内容加一条七步路径。第一块是“Agent 是什么”——它不是聊天机器人，而是能主动思考、调用工具、读写文件、把任务往下推进的“AI 员工”。第二块是“它长什么样”——用户看到的是一个工作台/工位，背后是模型、工具、技能和上下文。

第三块是“由什么组成”：Skill 负责一类任务的做法与流程，CLI 负责执行命令，MCP 负责连接外部系统与数据。三者分工不同：Skill 告诉 Agent“怎么做”，CLI 让它“能动手”，MCP 让它“够得着”外部工具和资料。

第四块是“从零搭的七步”：文案没有逐条列出七步名称，只概括为“从建工位到新窗口验证上岗”。可以确定的是，流程终点不是“搭完就算”，而是换一个新窗口做验证——确认 Agent 在没有当前对话上下文的情况下，仍能按 skill 和工具把任务跑通。

作者强调全程不用写代码，自己的选品、剪辑、做图 Agent 都是这么搭的。这说明重点在“配置与流程设计”，不是编程：把任务拆清楚、把 skill 写清楚、把工具接好，再验证。

关键点

  • Agent 不是聊天：能主动推进、调用工具、读写文件，才叫“干活”。
  • 四块框架：是什么、长什么样、由什么组成、七步怎么搭。
  • 三件套分工：Skill 管做法，CLI 管执行，MCP 管连接外部。
  • 七步路径：从建工位到验证上岗；具体七步需看视频正文。
  • 新窗口验证：换一个没有当前上下文的窗口还能跑，才算真的搭好。
  • 不写代码：重点是任务拆解、skill 编写与工具配置。

适合谁看

想自己搭一个 Agent、但被“框架/代码”吓住的人；以及搭完只在当前对话里能用、换窗口就失效的人。视频是流程框架，具体七步与配置需要跟着正文操作。
