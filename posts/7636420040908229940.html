关键点

  • messages 数组：把对话存成 role/content 的列表，模型按顺序读。
  • 上下文窗口：模型一次能看到的 token 上限，决定能塞多少历史与资料。
  • 系统提示：优先级最高的行为约束，定义角色、边界和输出格式。
  • 思维链 CoT：让模型先写推理步骤再给答案，提升复杂任务表现。
  • Few-Shot：在提示里给几个示例，让模型照着模式做。
  • 预填充 Prefill：先处理输入 token、建立 KV Cache，再开始逐 token 生成。
  • 停止序列：遇到指定字符串就停止生成，用来控格式和长度。
  • Tool Use：模型输出结构化的工具调用，由运行时执行后把结果送回。
  • RAG：先检索外部文档，再把相关片段放进上下文，减少胡编。
  • ReAct：推理与行动交替，边想边调工具，根据观察继续下一步。
  • 自回归生成：每次只预测下一个 token，再把新 token 接回输入。
  • Multi-Agent 编排：多个 Agent 分工、交接上下文，由编排层决定谁做什么。
